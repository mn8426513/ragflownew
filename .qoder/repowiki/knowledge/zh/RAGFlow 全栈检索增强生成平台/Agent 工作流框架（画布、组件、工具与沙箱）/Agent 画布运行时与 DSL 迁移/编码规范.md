- DSL 加载时先调用 `normalize_chunker_dsl` 做纯函数式结构迁移，再实例化组件，确保运行时始终持有最新 schema。
- 组件参数通过动态构造 `<ComponentName>Param` 类并调用 `check()` 进行统一校验，异常中附加组件可读名称以便定位。
- 变量引用统一采用 `{var}` 全局变量与 `{cpn_id@output.path}` 跨组件输出引用的双模式，解析逻辑集中在 `get_variable_value` / `set_variable_value` 中，路径分隔符使用 `.` 且支持 dict/list/对象属性多级访问。
- 运行时事件通过内部 `decorate(event, data)` 闭包统一封装 `message_id`、`task_id`、`created_at` 等元数据，保证所有事件结构一致。
- LLM 相关上下文（token 用量 sink、Langfuse 属性、OpenAI user/session）通过 `contextvars` 在 `run()` 的 try/finally 中设置并在 finally 中重置，防止跨 run 泄漏。
- DSL 迁移函数保持幂等与纯函数特性：对输入做深拷贝、仅改写结构标识符与字符串引用、不修改业务参数。
