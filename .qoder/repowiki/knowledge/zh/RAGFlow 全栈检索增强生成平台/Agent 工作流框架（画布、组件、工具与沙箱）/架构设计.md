模块以 `agent/canvas.py` 中的 `Graph`/`Canvas` 为运行时中枢：加载 JSON DSL → 通过 `component_class` 工厂把每个节点实例化为 `agent/component/base.ComponentBase` 子类 → 按 `path` 顺序调用各组件的 `invoke`/`invoke_async`，并通过 `get_variable_value`/`set_variable_value` 在 `globals` 与组件输出之间解析 `{var}` 和 `@cpn.output.path` 引用；并发由 `asyncio.Semaphore` + `ThreadPoolExecutor` 控制。
- `agent/component/` 提供图原语（begin/loop/iteration/switch/categorize/message 等），所有组件共享同一基类与参数校验契约。
- `agent/tools/` 实现具体外部能力（搜索、SQL、爬虫等），被组件或插件通过统一接口调用。
- `agent/plugin/` 通过 `plugin_manager` 动态加载 LLM Tool 插件，扩展组件可调用的工具集。
- `agent/sandbox/` 以 provider 抽象（`providers/base.py`）封装本地、SSH、E2B、阿里云等多种代码执行环境，由 `manager.py` 统一调度，供 `tools/code_exec.py` 及组件使用。
- `agent/templates/` 提供预置 DSL 模板，`agent/test/dsl_examples/` 提供测试用例；`dsl_migration.py` 将旧版 chunker DSL 归一化后交给 Canvas 消费。
- 跨子模块共享状态通过 Canvas 的 `globals`/`variables`、Redis 任务取消键、以及 `common.token_usage_sink` / `langfuse_run_attrs` 上下文变量传播到 LLM 与 TTS 调用链。
