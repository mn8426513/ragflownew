- 每个业务领域在 `apps/restful_apis/` 下以单文件形式暴露一组路由，并在同目录下对应的 `*_service.py` 中封装请求校验与业务编排，路由层仅做参数解析与结果包装。
- 数据库访问统一通过 `api/db/services/` 下的 Service 类实现，方法使用 `@DB.connection_context()` 装饰器管理连接，并以 `get_cls_model_fields()` 集中声明查询字段列表。
- 认证通过 `@login_required(auth_types=...)` 装饰器保护路由，支持 JWT、API Token、Beta Token 与 Session 四种模式，未认证请求统一抛出 `QuartAuthUnauthorized` 由全局错误处理器返回标准 JSON。
- 多渠道 Channel 通过 `core/registry` 的构建器模式自注册，新增通道只需在 `_BUNDLED_CHANNELS` 元组中添加包名，无需修改核心调度逻辑。
- 全局异常通过 `common.exceptions` 中定义的自定义异常类表达语义（如 `AdminException`、`UserNotFoundError`），并由 `apps/__init__.py` 中的 `errorhandler(ModelException)` 统一序列化为 `{code, message, data}` 格式。
- 所有 HTTP 响应经 `api.utils.api_utils.get_json_result` 或 `server_error_response` 包装，保证统一的 `{code, message, data, error}` 结构，避免直接返回裸字典。
