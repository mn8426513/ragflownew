单二进制通过命令行模式切换进程：`--api`（默认）、`--admin`、`--ingestor`、`--syncer`；通用选项包括 `-f/--config` 指定配置文件路径、`-p/--port` 覆盖端口、`--debug` 开启调试日志、`--init-superuser`（仅 admin 模式初始化超级管理员）、`--migrate` 执行数据库迁移；配置文件默认查找顺序为 `./conf/service_conf.yaml` → `./service_conf.yaml` → `/etc/ragflow/service_conf.yaml`，且可通过 `RAGFLOW_*` 环境变量覆盖。
