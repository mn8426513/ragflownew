- 每个 HTTP 功能域拆分为 handler/service/dao 三层，handler 仅做参数绑定与响应封装，业务逻辑下沉至 service，数据访问下沉至 dao。
- 路由按权限粒度分组：无认证组 (`apiNoAuth`)、Beta Token 认证组 (`apiBetaAuth` 使用 `BetaAuthMiddleware`)、普通鉴权组 (`AuthMiddleware`)，新增端点需归入对应组。
- 企业版功能通过 `_ee.go` 后缀文件与开源代码并存，由构建标签或运行时条件加载，避免破坏基础版本编译。
- 外部依赖（文档引擎、消息队列、存储、MCP、导航服务等）通过包级 setter 函数（如 `nav.SetNavService`、`component.SetMemorySaver`、`agenttool.SetRetrievalService`）在进程启动时注入，而非构造函数传参。
- 配置统一通过 `server.Init` 加载到全局 `globalConfig`，各子模块通过 `GetAPIServerConfig`/`GetIngestorConfig` 等 getter 读取，禁止直接访问 viper。
- HTTP 服务器启动采用 goroutine + `signal.NotifyContext` 监听 SIGINT/SIGTERM/SIGQUIT，收到信号后调用 `srv.Shutdown` 进行带超时的优雅关闭。
