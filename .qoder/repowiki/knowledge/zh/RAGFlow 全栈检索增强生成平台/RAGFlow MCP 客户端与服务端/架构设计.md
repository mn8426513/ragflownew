模块按职责分为 client 与 server 两个子包：
- client/：提供两种连接方式——client.py 使用 `mcp.client.sse.sse_client` 通过 `/sse` + `/messages/` 走传统 SSE；streamable_http_client.py 使用 `mcp.client.streamable_http.streamablehttp_client` 通过 `/mcp/` 走 Streamable HTTP。两者均基于 `ClientSession` 完成 initialize → list_tools → call_tool 的标准 MCP 调用流程。
- server/server.py：以 `mcp.server.lowlevel.Server` 为核心，通过 `@app.list_tools()` 和 `@app.call_tool()` 注册三个工具（ragflow_retrieval、ragflow_list_datasets、ragflow_list_chats），并在 `call_tool` 中按 name 分发到对应业务逻辑。后端交互封装在 `RAGFlowConnector` 中，使用 httpx.AsyncClient 访问 RAGFlow 内部 REST API（/datasets、/chats、/retrieval 等），并内置带 TTL 的 LRU 式本地缓存（`_dataset_metadata_cache`、`_document_metadata_cache`）以减少重复请求。认证通过 `with_api_key` 装饰器从请求头或生命周期上下文提取 Bearer/api_key，支持 self-host（单租户固定密钥）与 host（多租户，每请求鉴权）两种 LaunchMode。HTTP 层由 Starlette 组装，根据 `TRANSPORT_SSE_ENABLED` / `TRANSPORT_STREAMABLE_HTTP_ENABLED` 开关动态挂载 `/sse`、`/messages/`、`/mcp` 路由，并通过 uvicorn 启动。CLI 入口为 click 命令，参数同时可从环境变量 `RAGFLOW_MCP_*` 注入。
