服务端通过 `uv run mcp/server/server.py` 启动，支持 --mode=self-host|host、--api-key、--transport-sse-enabled/--no-transport-sse-enabled、--transport-streamable-http-enabled/--no-transport-streamable-http-enabled、--json-response/--no-json-response 等选项；所有配置也可通过 RAGFLOW_MCP_BASE_URL/RAGFLOW_MCP_HOST/RAGFLOW_MCP_PORT/RAGFLOW_MCP_LAUNCH_MODE/RAGFLOW_MCP_HOST_API_KEY/RAGFLOW_MCP_TRANSPORT_SSE_ENABLED/RAGFLOW_MCP_TRANSPORT_STREAMABLE_ENABLED/RAGFLOW_MCP_JSON_RESPONSE 环境变量覆盖。客户端示例直接运行 `python mcp/client/client.py` 或 `python mcp/client/streamable_http_client.py`。
