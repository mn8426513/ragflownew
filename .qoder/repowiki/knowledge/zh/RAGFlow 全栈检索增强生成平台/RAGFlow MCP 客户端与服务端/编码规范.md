- MCP 工具通过 `@app.list_tools()` 声明 Tool 元数据（name/description/inputSchema），再由 `@app.call_tool()` 中的 name 分支进行具体实现，形成声明与执行分离的双注解模式。
- 需要鉴权的工具方法统一使用 `@with_api_key(required=True)` 装饰器，从请求头或 lifespan_context 中提取 api_key/Bearer token 并注入 connector 与 api_key 参数。
- 对后端 REST API 的访问统一封装在 `RAGFlowConnector` 中，通过 `_get`/`_post` 方法复用 httpx.AsyncClient，并以 `Authorization: Bearer <api_key>` 形式传递凭证。
- 分页拉取后端列表数据时采用 while True 翻页直到返回页大小小于 page_size 为止，避免依赖 total 字段导致漏数据。
- 易变元数据（数据集、文档）使用 OrderedDict + TTL 时间戳做 LRU 缓存，超过 _MAX_DATASET_CACHE 时自动淘汰最久未使用的条目。
- 错误路径统一抛出包含 `types.TextContent` 的 Exception，使 MCP 框架将后端错误以文本内容形式返回给调用方。
