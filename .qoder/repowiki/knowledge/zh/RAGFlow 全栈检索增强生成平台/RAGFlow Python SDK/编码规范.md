- 所有资源类继承自 `Base`，通过构造时传入的 `res_dict` 动态生成属性，并使用 `to_json()` 进行反向序列化。
- HTTP 响应统一采用 `{code, message, data}` 结构，成功时 `code == 0`，失败时抛出 `Exception(res['message'])`。
- 分页查询方法固定包含 `page`、`page_size`、`orderby`、`desc` 参数，并按资源域组织为独立的 list/get/create 方法族。
- 可选参数通过 `if xxx is not None:` 条件拼接到 payload 或 params 中，避免向 API 发送空字段。
- 需要长时间等待的操作（如文档解析）采用异步调用 + 轮询状态的模式，并在捕获 `KeyboardInterrupt` 时主动取消任务。
- 测试通过 pytest fixture 在会话级完成环境初始化（注册、登录、配置模型），并以 `HOST_ADDRESS`、`ZHIPU_AI_API_KEY` 等环境变量隔离不同部署。
