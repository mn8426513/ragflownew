模块由三个文件构成应用启动与路由装配层：`main.tsx` 作为 Vite 入口，先并行执行 `initLanguage()` 与 `fetchBackendLanguage()` 完成国际化与后端语言探测后再渲染 `<App />`，并包裹 `React.StrictMode` 与开发期 `react-dev-inspector`；`app.tsx` 组装根级 Provider 链——`TooltipProvider` → `QueryClientProvider`（配置默认重试次数与窗口聚焦行为）→ `ThemeProvider`（默认深色主题，持久化 key 为 `ragflow-ui-theme`）→ 自定义 `Root`（注入企业水印、Sonner/Toaster 通知），并通过 `RouterProviderWrapper` 注入路由实例；`routes.tsx` 集中声明所有路由，通过 `Routes` 枚举统一管理路径常量，使用 `withLazyRoute` 包装器对页面组件进行 `React.lazy` + `Suspense` 懒加载，并以 `wrapRoutes` 递归遍历嵌套路由统一注入 `FallbackComponent` 错误边界；根路由 `/` 的 `loader` 在首次渲染时从 URL 查询参数提取 `auth` 令牌写入 `authorizationUtil` 并重定向清理参数，支持按功能域（datasets/chats/admin 等）组织子路由，admin 模块还通过 `IS_ENTERPRISE` 条件动态注册企业版路由。依赖方向单向：`main.tsx` → `app.tsx` → `routes.tsx`，路由仅引用页面组件与共享工具，不反向依赖业务逻辑。
