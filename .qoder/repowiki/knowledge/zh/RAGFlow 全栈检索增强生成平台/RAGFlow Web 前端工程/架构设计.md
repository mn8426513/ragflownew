以 `src/main.tsx` 为入口挂载 React 根节点，通过 `src/routes.tsx` 集中声明式注册所有页面路由（使用 react-router v7 的 createBrowserRouter），并按业务域拆分为 pages/admin、pages/agent、pages/dataset、pages/next-chats、pages/next-search、pages/memory、pages/files、pages/skills、pages/user-setting 等子模块；每个页面模块内部再按 components/hooks/services/interfaces 分层组织。跨子模块的协作契约集中在：`src/interfaces/` 定义数据库与请求类型、`src/services/` 封装各后端 API、`src/hooks/` 暴露 use-*-request 组合式 Hook、`src/utils/request.ts` 统一 axios 拦截与鉴权、`src/layouts/root-layout.tsx` 提供全局导航与主题上下文、`src/locales/*` 提供多语言文案。构建与开发由根级 `vite.config.ts`、`tailwind.config.js`、`jest.config.ts`、`.storybook/main.ts` 统一驱动，husky 钩子在提交前执行 oxfmt/oxlint 校验。
