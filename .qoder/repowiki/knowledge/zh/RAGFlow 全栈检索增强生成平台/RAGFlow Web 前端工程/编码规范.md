- 页面路由统一在 `src/routes.tsx` 中以 `routeConfigOptions` 数组声明，并通过 `withLazyRoute` 包裹实现按需懒加载与 Suspense fallback。
- 所有业务常量（路径、枚举、配置）集中在 `src/constants/` 下按领域拆分文件，避免硬编码字符串散落各处。
- API 调用遵循 services/hooks 两层：`src/services/*.ts` 封装 axios 请求，`src/hooks/use-*-request.ts` 基于 @tanstack/react-query 暴露带缓存与重试的组合式 Hook。
- 类型定义按领域分文件存放于 `src/interfaces/database/` 与 `src/interfaces/request/`，供页面、hooks、services 共同引用。
- 可复用 UI 组件放在 `src/components/ui/`（基础原子组件）或 `src/components/<feature>/`（业务组件），并通过 barrel 导出。
- 样式采用 Tailwind 原子类为主，局部复杂样式使用同目录 `.module.less` 文件并配合 `src/less/variable.less` 中的全局变量。
