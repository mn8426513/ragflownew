本模块为纯示例代码，按接入方式划分为三个并列子目录：
- `sdk/`：基于 `ragflow_sdk.RAGFlow` 客户端的 Python 脚本，每个文件对应一个能力（chat_assistant、chunk、dataset、document、retrieval），通过环境变量 `RAGFLOW_HOST_ADDRESS` 与 `RAGFLOW_API_KEY` 配置服务端地址与鉴权。
- `http/`：使用 `curl` + `jq` 直接调用 `/api/v1/datasets/...` REST 接口，脚本结构与 `sdk/` 一一对应，便于对比同一功能在两种调用方式下的差异。
- `chat_demo/`：纯前端 HTML，通过 `<iframe>` 嵌入本地 `localhost:9222` 的聊天小部件，并通过 `postMessage` 监听 `CREATE_CHAT_WINDOW`、`TOGGLE_CHAT`、`SCROLL_PASSTHROUGH` 事件实现页面内嵌交互。
三者之间无相互依赖，均面向已部署的 RAGFlow 服务，仅作为独立可运行的演示入口。
