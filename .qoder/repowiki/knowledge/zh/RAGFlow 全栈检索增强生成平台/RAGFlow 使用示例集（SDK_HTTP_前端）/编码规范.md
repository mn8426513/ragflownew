- 所有示例通过 `os.environ.get` / shell 变量读取 `RAGFLOW_HOST_ADDRESS` 与 `RAGFLOW_API_KEY`，并提供合理的默认值以支持本地快速运行。
- SDK 与 HTTP 脚本按能力一一对应命名（chat_assistant、chunk、dataset、document、retrieval），便于横向对照同一功能的两种调用方式。
- HTTP 脚本统一使用 Bearer Token 鉴权头 `Authorization: Bearer ${API_KEY}`，并以 `curl -s ... | jq .` 格式化输出 API 响应。
- 示例脚本在执行完主要流程后主动清理创建的资源（删除 session、assistant、dataset），保证可重复执行。
