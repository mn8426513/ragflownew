文档以 Docusaurus 多语言站点结构组织，根目录 `_category_.json` 定义一级导航分类（如 Get Started、User Guides），各子目录通过各自的 `_category_.json` 声明二级/三级分类、侧边栏图标与排序位置；内容按角色与主题分层：`basics/` 提供基础概念，`guides/` 按功能域（agent、chat、dataset、team 等）细分，`administrator/` 面向运维配置与升级，`develop/` 面向源码构建与 MCP 集成，`references/` 提供术语、HTTP/Python API 参考。页面统一使用 MDX（`.mdx`）以嵌入 React 组件（如 `Tabs`、`TabItem`、`APITable`），并通过 front matter 控制 `sidebar_position`、`slug` 与自定义属性（如 `sidebarIcon`）。站点入口为 `quickstart.mdx`，通过相对路径跨模块引用其他文档，形成单向依赖的文档树。
