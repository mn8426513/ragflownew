模块以 `rag/` 为根，按职责划分为若干子包，依赖方向自下而上：
- 基础设施层：`llm/` 提供统一 LLM 抽象（`chat_model.py` 中的 `Base` 及 Xinference/HuggingFace/ModelScope/BaiChuan 等子类），通过 OpenAI/LiteLLM 客户端访问后端；`utils/` 封装多种存储连接（S3/OSS/MinIO/ES/OpenSearch/Redis/GaussDB/Infinity 等）并通过 `storage_factory.py` 工厂暴露；`nlp/` 提供分词、同义词、查询改写等基础 NLP 能力。
- 流程编排层：`flow/pipeline.py` 继承 `agent.canvas.Graph` 实现文档摄入 DAG（File→Parser→Chunker→Extractor→Tokenizer→Indexer），通过 JSON DSL 定义组件依赖，使用 Redis 推送进度；`flow/{parser,chunker,extractor,tokenizer,compiler}` 各自维护 schema 与具体实现，支持标题分块、token 分块等多种策略。
- 应用层：`app/` 下每个文件对应一种文档类型或业务场景（`one.py` 通用解析、`paper.py`、`book.py`、`qa.py`、`resume.py`、`table.py` 等），统一暴露 `chunk(filename, binary, ...)` 接口，复用 `deepdoc.parser` 与 `rag.nlp`。
- 高级检索层：`advanced_rag/` 实现 Agentic-RAG，`agentic_rag.py` 的 `RAGTools` 聚合问题形式化、关键词抽取、KB/Web/结构化检索、充分性判断与追问生成，并通过 `agentic_rag_graph.py` 驱动 LangGraph 工作流；`harness/` 提供工具、统计、会话与提示模板。
- GraphRAG 层：`graphrag/` 分为 `general/`（Leiden 社区发现、实体/关系抽取、社区报告）、`light/`（轻量图抽取）和 `ner/`（依存句法+NER），共享 `entity_resolution`、`search`、`checkpoints` 等公共逻辑。
- 服务端执行层：`svr/task_executor*.py` 与 `task_executor_refactor/` 将上述管道包装为可异步执行的后台任务，通过 `task_manager` 调度并持久化中间状态。
- 提示工程：`prompts/` 集中管理所有 `.md` 提示模板，由 `generator.py` 与 `template.py` 加载渲染，被 `advanced_rag`、`graphrag`、`app/*` 多处复用。
- 顶层 `settings.py` 与 `benchmark.py` 提供全局配置与性能基准入口。
