运行前需执行 `uv sync --python 3.13 --only-group test --no-default-groups --frozen` 安装测试依赖并 `uv pip install sdk/python` 安装 SDK；通过 `docker compose -f docker/docker-compose.yml up -d` 启动后端，并在 `.env` 中设置 `COMPOSE_PROFILES=...,tei-cpu`、`TEI_MODEL=BAAI/bge-small-en-v1.5`、`RAGFLOW_IMAGE=...`。HTTP 集成测试通过 `export HTTP_API_TEST_LEVEL=p2 && export HOST_ADDRESS=http://127.0.0.1:9380` 后执行 `pytest -s --tb=short --level=${HTTP_API_TEST_LEVEL} test/testcases/test_sdk_api`；Infinity 引擎需额外设置 `DOC_ENGINE=infinity`。Playwright E2E 使用 `BASE_URL`/`E2E_ADMIN_EMAIL`/`E2E_ADMIN_PASSWORD` 环境变量运行 `uv run pytest -q test/playwright`。Benchmark 通过 `PYTHONPATH=./test uv run -m benchmark chat|retrieval ...` 调用。
