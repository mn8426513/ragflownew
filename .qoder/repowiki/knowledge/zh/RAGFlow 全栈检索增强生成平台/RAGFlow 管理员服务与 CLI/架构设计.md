模块分为 server 与 client 两个子目录：
- server/ 以 `admin_server.py` 为入口，使用 Flask + Flask-Login + flask-session 启动 WSGI 服务（端口 9381），注册 `routes.admin_bp`（URL 前缀 `/api/v1/admin`）。路由层（`routes.py`）仅负责参数解析与异常包装，业务逻辑委托给 `services.py` 中的各 `*Mgr` 类（UserMgr、ServiceMgr、UserServiceMgr、SettingsMgr、ConfigMgr、EnvironmentsMgr、SandboxMgr）以及 `roles.py`（RoleMgr）、`enterprise.py`（AuditMgr、DepartmentMgr、SecurityMgr、SsoMgr、WhitelistMgr）。认证由 `auth.py` 通过 `setup_auth` 注入 `request_loader`，从 Authorization 头解码 JWT access_token 并查询数据库；默认超级管理员通过 `init_default_admin` 在启动时按环境变量优先级创建。
- client/ 提供独立 Python 包（`pyproject.toml` 定义），入口 `ragflow_cli.py` 基于 `cmd.Cmd` 实现交互式 REPL，使用 Lark 语法解析自定义命令语言，调用 `ragflow_client.RAGFlowClient` 封装的 HTTP 请求，并通过 `http_client.HttpClient` 统一处理鉴权（web/admin 两种 auth_kind）与重试。
依赖方向单向：client → server HTTP API；server → 共享 `api.db.*` 服务层与 `common.*` 工具，不反向依赖 client。
