- 路由函数统一使用 `@login_required` 与 `@check_admin_auth` 装饰器组合保护，并在 try/except 中将业务异常 `AdminException` 转为 `error_response(e.message, e.code)`，其他异常转为 500 错误响应。
- 所有成功响应通过 `responses.success_response(data, message, code=0)` 返回，失败响应通过 `responses.error_response(message, status_code)` 返回，保证 API 返回格式一致。
- 业务逻辑集中在 `services.py` 与各 `*Mgr` 类的静态方法中，路由层只做参数提取与转发，不直接操作数据库模型。
- CLI 中每个命令方法先检查 `self.server_type != 'admin'/'user'` 再执行，确保命令只能在对应模式下运行。
- CLI 对服务器响应统一判断 `response.status_code == 200` 且 `res_json['code'] == 0` 才视为成功，否则打印包含 code 与 message 的错误信息。
- 管理员密码在传输时使用 PyCryptodome 内置固定公钥进行 RSA 加密后再提交到后端，避免明文传输。
