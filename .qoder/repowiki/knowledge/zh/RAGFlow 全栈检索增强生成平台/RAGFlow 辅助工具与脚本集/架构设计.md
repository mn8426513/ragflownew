本模块按职责拆分为多个独立可执行的子工具，彼此无运行时依赖，仅共享仓库根路径约定：
- `tools/es-to-oceanbase-migration/`：基于 hatchling + click 的 Python 包（`pyproject.toml` 暴露 `es-ob-migrate` 入口），内部按 `cli.py` → `migrator.py` → `es_client.py`/`ob_client.py` → `schema.py`/`verify.py`/`progress.py` 分层，通过 Click group 提供 migrate/schema/verify/list-indices/list-kb/status/sample 等子命令。
- `tools/firecrawl/`：异步 aiohttp 客户端封装，`firecrawl_connector.py` 定义 `ScrapedContent`/`CrawlJob` dataclass 并通过 `__aenter__`/`__aexit__` 管理会话，`firecrawl_processor.py`、`integration.py`、`ragflow_integration.py` 在其之上实现处理与 RAGFlow 对接，`firecrawl_ui.py` 提供 CLI 入口。
- `tools/chatgpt-on-wechat/plugins/ragflow_chat.py`：作为 chatgpt-on-wechat 框架的 Plugin，通过 `@register` 装饰器注册事件处理器 `on_handle_context`，调用 RAGFlow `/v1/api/new_conversation` 与 `/v1/api/completion` 完成对话。
- `tools/gen-component-parity/main.go` 与 `tools/migrate-canvas/main.go`：Go 单文件工具，分别反射 `internal/agent/component` 与 `internal/agent/tool` 注册表生成 Markdown 矩阵，以及调用 `dsl.NormalizeForCanvas` 对 DSL JSON 做规范化并支持 `-golden` CI 比对模式。
- `tools/scripts/db_schema_sync.py`：基于 peewee + peewee-migrate，动态加载 `api/db/db_models.py` 中的 Model 子类，对比 MySQL `information_schema.columns` 生成带 rollback 的迁移文件到 `tools/migrate/{version}/`。
- `tools/hooks/check_files.py`：Git pre-commit hook，通过 `git diff --cached` 获取暂存文件并对 json/yaml/eof/空白行/混合换行/合并冲突/符号链接/大小写冲突/注释 ASCII 进行校验。
- `scripts/fetch_deepdoc_testdata.sh`：通过 git sparse-checkout 从外部 `infiniflow/ragflow-testdata` 仓库按 tag 拉取 DeepDoc 测试数据并以 symlink 或拷贝形式注入 `internal/deepdoc/<pkg>/testdata`。
- `tools/render_diff/warp_align.py`、`tools/scripts/*.sh`、`install.ps1` 等为一次性运维/渲染辅助脚本。
