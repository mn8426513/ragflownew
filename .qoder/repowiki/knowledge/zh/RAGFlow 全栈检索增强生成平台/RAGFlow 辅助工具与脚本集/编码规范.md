- CLI 工具统一通过命令行参数解析（click/group/command 或 argparse/flag）暴露子命令，并在异常时输出彩色日志后以非零退出码结束。
- 网络客户端采用上下文管理器（`__aenter__`/`__aexit__`）管理 aiohttp ClientSession，并在请求层集中实现速率限制、重试与指数退避。
- 数据模型使用 dataclass 表示 API 响应（如 ScrapedContent、CrawlJob），字段均声明 Optional 类型以区分成功与失败路径。
- Go 工具通过反射生产文档/矩阵，对无法构造的组件/工具返回占位标记而非抛错，保证表格完整性。
- 数据库 schema 同步脚本将自定义 Peewee Field 映射为标准类型后再比较，并为新增/修改/删除字段同时生成 forward 与 rollback SQL。
- Git hooks 统一通过 `_is_binary` 检测 NUL 字节跳过二进制文件，所有检查函数签名一致 `(paths, fix=False)` 并返回统一错误计数。
