- Compose 与 Helm 通过同名环境变量（如 DOC_ENGINE、MYSQL_*、MINIO_*、REDIS_PASSWORD、TZ）保持配置语义一致，便于在两种环境间切换。
- RAGFlow 服务配置采用模板化注入：Compose 挂载 `service_conf.yaml.template`，Helm 通过 `ragflow_config.yaml` 生成 `local.service_conf.yaml` 覆盖到 `/ragflow/conf/`。
- Nginx 反向代理配置拆分为 `nginx.conf` + `proxy.conf` + 多份 `ragflow.conf.*`（python/go/hybrid/https），按运行语言与协议选择挂载不同配置文件。
- Helm 模板中每个可插拔组件（mysql/minio/redis/elasticsearch/opensearch/infinity）拥有独立的 `image.repository/tag/pullPolicy/pullSecrets` 与 `deployment.resources` 段，便于单独开关与调参。
- Helm 使用 `checksum/values`、`checksum/config-env`、`checksum/config-ragflow` 注解触发滚动更新，确保 ConfigMap/Secret 变更时 Pod 自动重建。
- Compose 通过 `profiles`（cpu/gpu）区分不同硬件能力的需求，GPU 模式额外声明 `deploy.resources.reservations.devices` 以申请 NVIDIA GPU。
