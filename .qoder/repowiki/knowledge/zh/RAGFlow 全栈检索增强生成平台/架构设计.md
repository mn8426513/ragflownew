项目采用多语言多进程架构：Python 侧由 `api/ragflow_server.py` 启动 Quart HTTP 服务（端口 9380）并配合 `rag/svr/task_executor.py` 从 Redis Stream 消费文档处理任务；Go 侧由 `internal/cmd/server_main.go` 等入口以单二进制启动 API/Admin/Ingestor/Syncer 四种进程模式（端口 9383/9384），二者可通过 `API_PROXY_SCHEME` 环境变量在前端代理层混合路由。所有子模块共享 `conf/service_conf.yaml` + `.env` + 运行时环境变量构成的配置体系，并通过 `common/settings.py` 初始化数据库、ES/Infinity/OceanBase 索引、Redis、对象存储及 LLM 元数据。数据流贯穿 deepdoc→rag flow pipeline→doc_store→LLM，Agent 画布 DSL 经 `agent/canvas.py` 拓扑执行后复用同一检索与记忆能力。部署层由 `docker/docker-compose.yml` 与 `helm/` 将 MySQL、Redis、MinIO、Nginx 与上述进程编排在一起，前端 `web/` 通过 Vite 代理统一访问 `/v1` 与 `/api/v1` 两套 API。
