- 各语言子模块均通过独立的 `pyproject.toml` / `go.mod` 声明依赖，并在根级 `pyproject.toml` 中集中锁定版本与 CVE 约束依赖。
- 服务进程通过 `conf/service_conf.yaml` + `.env` + 环境变量三层覆盖加载配置，并由 `common/settings.py` 统一初始化外部连接。
- API 路由按功能域拆分文件（dataset/document/chat/agent 等），RESTful 路由统一挂载到 `/api/v1/`，传统路由挂载到 `/v1/<page>/`，并通过蓝图自动发现注册。
- 组件与工具通过文件系统扫描 + importlib 动态发现并注册（如 agent/component、agent/tools），新增实现无需修改中心注册表。
- 测试使用 pytest markers（p0/p1/p2/p3、smoke、auth、asyncio）进行优先级与场景分类，并按模块镜像源码结构组织用例。
